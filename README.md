🔗 **Ver no navegador:** https://rafasdiass.github.io/vigora-mockups/

## Acessibilidade

Contraste verificado contra **WCAG 2.1 AA**:
- Texto principal `mist #F5F7FA` sobre `night` → **16:1** (AAA)
- Texto secundário `slate #8793A6` sobre `night` → **5.6:1** (AA)
- Acento `#5C92FF` sobre escuro → **5.8:1**; texto azul em fundo claro usa `#2563EB` (**4.8:1**)

Fundo escuro com texto claro = alto contraste (o lado correto da régua).
